Theme: Web programming

Pair with the HTML, CSS, and JavaScript tutorials if you want a guided warm-up before you build.

Light experience

Ship a small, real webpage you can open in a browser: structure, style, and one interactive touch. Prefer a finished single page over a half-built multipage site.

Project ideas

  1. Personal landing page — Name, short bio, links to projects or socials, and a color palette that feels like you.
  2. Event flyer as a webpage — Date, time, place, and a clear CTA; make it look good on a phone.
  3. Recipe or how-to card — Ingredients/steps with headings, a checklist, and simple print-friendly styles.
  4. Link-in-bio page — A short stack of styled buttons to your favorite places on the web.
  5. Dark/light theme toggle — One page, two color schemes, switched with a button and a little CSS.

Learning goals

  • Semantic HTML: headings, lists, links, and landmarks
  • CSS layout with flexbox or simple grid
  • One DOM event in JavaScript (click, input, or submit)
  • Opening a local .html file (or a tiny static server) and iterating in DevTools

Heavy experience

Build a small multi-section site (or a tiny web app) with navigation, reusable layout, and client-side behavior that goes beyond a single button.

Project ideas

  1. Portfolio site — Home, about, and projects pages (or one long page with in-page nav); shared header/footer styles.
  2. Club / meetup homepage — Hero, next event, FAQ, and a contact or RSVP form (form can be front-end only).
  3. Interactive gallery — Grid of images or cards with a lightbox/modal detail view.
  4. Client-side filter/search — A list of items (books, recipes, local spots) filtered by tags or a search box—no backend required.
  5. Static site with a build step — Optional stretch: Eleventy, Vite, or similar to share CSS/JS across pages.

Learning goals

  • Consistent layout and typography across sections
  • Responsive breakpoints and mobile-first habits
  • Forms, basic validation, and accessible focus states
  • Organizing files (index.html, css/, js/) so others can run your project

Suggested session flow

  1. Pick light or heavy and sketch the page wireframe (boxes only—no pixel polish yet).
  2. Write the HTML structure first; add CSS second; add JavaScript last.
  3. Check the page on a narrow window before you demo.
  4. Demo: open the live page, click through one happy path, and name one thing you’d add next time.
