WordPress powers a huge share of the web—including many library, school, and nonprofit sites. Pages are the long-lived parts of a site (About, Hours, Events, Contact). This guide walks you through creating and editing them in the block editor, with curated practice links at the end.

Pages vs posts (the mental model)

WordPress has two main content types. Mixing them up is the most common beginner trip-up:

  • Pages — Evergreen content. They live in a hierarchy (About → Staff), often show up in menus, and do not appear in the blog feed by default.
  • Posts — Time-stamped items (news, announcements). They use categories and tags and show up in reverse-chronological lists.

Rule of thumb: if it still matters next year without a date in the title, make a page. If it’s “this week’s program update,” make a post.

Before you start

You need a WordPress site you can log into, plus a role that can edit pages (Editor or Administrator is typical). Options for practice:

  • A local install (Local, Docker, or XAMPP + WordPress)
  • A free WordPress.com site (features differ slightly from self-hosted)
  • A staging site your organization already uses

Always prefer a staging or practice site over editing a live public homepage until you’re comfortable.

Create your first page

  1. Log in to the admin dashboard (usually yoursite.org/wp-admin).
  2. In the left sidebar: Pages → Add New.
  3. Type a clear title at the top (e.g. “Hours & Location”). The title becomes the default URL slug.
  4. Add content with blocks (see below)—start with a short paragraph, then a heading, then more paragraphs or a list.
  5. Open the right-hand Page settings (gear / sidebar) for status, parent, template, and featured image.
  6. Click Save draft, then Preview, then Publish when it looks right.

You can also create pages from the Site Editor on block themes: Appearance → Editor → Pages, then the plus icon. Content editing works the same; you’re just seeing the page inside its template.

The block editor (Gutenberg)

Since WordPress 5.0, pages are built from blocks—paragraphs, headings, images, buttons, columns, and more—stacked like Lego. You do not need to write HTML to publish a solid page (though you can drop into a Custom HTML block when you want to).

Core workspace

  • Canvas — The middle of the screen; click and type.
  • Inserter (+) — Search and add blocks, patterns, or media.
  • List View — Outline of every block; great for reordering and nested layouts.
  • Block settings — Right sidebar options for the selected block (alignment, color, typography).
  • Page / Post settings — Right sidebar for the whole page (status, slug, parent, template).

Everyday block moves

  • Press Enter in a paragraph to start a new block; use the + or type / to pick a block type by name.
  • Select a block, then use the toolbar to transform it (e.g. paragraph → heading), align it, or move it up/down.
  • Use List View to drag blocks—safer than hunting tiny handles on a long page.
  • Patterns are pre-built sections (hero, FAQ, call-to-action). Insert one, then swap the placeholder text and images for yours.

Write content people can actually use

A good WordPress page is mostly clear writing and hierarchy—not fancy layout.

  • Lead with the answer. Hours, address, and “how do I…?” belong near the top.
  • One job per page. “Hours & Location” and “Meeting Room Policies” can be separate pages linked from a parent “Visit” page.
  • Headings as a map. Skim your List View: if the outline doesn’t make sense, fix the headings before you polish colors.
  • Links with honest labels. Prefer “Download the program PDF” over “click here.”
  • Images with purpose. Compress large photos before upload; WordPress can resize, but huge originals slow editors and visitors.

Page settings that matter

Status & visibility

  • Draft — Only editors see it; safe while you’re writing.
  • Pending review — Ready for someone else to approve (if your workflow uses it).
  • Published — Live (or scheduled) for the public.
  • Private / password-protected — Limited access; useful for staff-only notes, not for general secrets.

Permalink (slug)

The slug is the URL piece after your domain, e.g. /hours/. Edit it under page settings or via Quick Edit on the Pages list. Keep it short, lowercase, and hyphenated. Change carefully after a page is linked from menus or printed materials—broken links confuse patrons.

Parent page & order

Set a Parent to nest pages: Visit → Hours, Visit → Parking. WordPress can show this hierarchy in menus and breadcrumbs (theme-dependent). Order is a number used by some themes and menus when sorting siblings—lower numbers often appear first.

Featured image & excerpt

A featured image is the thumbnail themes use in cards, headers, or social previews. An excerpt is a short blurb for listings. Not every theme uses them on pages; check your theme’s docs or Preview with and without one.

Templates

Some themes offer page templates (full width, no sidebar, landing). Pick the template that matches the job—don’t force a blog-sidebar layout onto a marketing-style landing page.

Menus: how visitors find your page

Publishing a page does not automatically put it in the site navigation. After you publish:

  1. Go to Appearance → Menus (classic) or edit the Navigation block in the Site Editor (block themes).
  2. Add your page to the menu, nest it under a parent item if needed, and save.
  3. Preview the front of the site on a phone-width window—menus behave differently on small screens.

Preview, publish, revise

  1. Preview in a new tab before first publish.
  2. Publish when the content is accurate—not when the design is “perfect.”
  3. Revisit later via Pages → All Pages; use Quick Edit for slug, parent, and status without opening the full editor.
  4. If something breaks the layout, open List View and remove or regroup the last blocks you added—nested Groups and Columns are usually the culprit.

Accessibility quick checks

  • Use real heading levels, not bold paragraphs pretending to be headings.
  • Alt text for meaningful images; empty/decorative images should be marked decorative when the UI allows.
  • Don’t rely on color alone (“items in red are closed”).
  • Ensure button and link text makes sense out of context.
  • Check contrast if you override theme colors.

Handy keyboard shortcuts

/          Open block inserter (in an empty paragraph)
Ctrl/Cmd+Z Undo
Ctrl/Cmd+S Save draft
Shift+Alt+O Toggle List View (often)
Enter      New block after current

Shortcuts vary slightly by OS and WordPress version—open the editor’s options menu (⋮) → Keyboard shortcuts for the live list.

A small practice page

  1. Create a page titled “Visit Us.”
  2. Add an H2 “Hours,” a short list of weekday hours, an H2 “Address,” and a paragraph with a made-up street address.
  3. Add a Buttons block linking to your library’s real homepage (or # for practice).
  4. Set a parent page (or create “About” and nest “Visit Us” under it).
  5. Save draft → Preview → Publish → add the page to a menu.
