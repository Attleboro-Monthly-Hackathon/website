Google Sheets is a spreadsheet that lives in the browser. You can share it with a link, edit it with others at the same time, and use formulas the same way you would in Excel—without installing anything. This session’s goal is to leave with one useful sheet you understand well enough to keep building on.

You need a free Google account. Work in a practice spreadsheet you create tonight; do not put real patron data or private library records in a shared demo sheet.

Open Google Sheets

  • Go to sheets.google.com and sign in.
  • Click Blank spreadsheet (or File → New → Spreadsheet).
  • Click the title at the top and name it something clear, e.g. APL practice — event headcount.

A workbook is the whole file. Tabs at the bottom are individual sheets. Each box is a cell; cells have addresses like A1 (column letter + row number). A range is a block such as A1:B10.

Beginner track

Leave with a tidy table, two or three formulas, a frozen header, and a share link you control.

1. Make a useful table

In row 1, enter headers. Example for a meetup sign-in sheet:

ABCD
NameRoleRSVPChecked in?

Fill a few sample rows (made-up names are fine). Select the header row → View → Freeze → 1 row so headers stay visible while you scroll. Select the data → Data → Create a filter to sort or filter by column.

  • Bold the header row; keep body text plain.
  • Use Format → Number when a column is dates or currency—don’t type $ by hand if you can avoid it.
  • One fact per column. Don’t combine “Ada / beginner / yes” in a single cell.

2. Totals and counts

Below your table (or off to the side), try:

=COUNTA(A2:A50)
=COUNTIF(D2:D50, "Yes")
=SUM(E2:E50)
  • COUNTA counts non-empty cells (good for “how many names?”).
  • COUNTIF counts cells that match a condition.
  • SUM adds numbers. Put quantities or dollar amounts in their own column first.

Press Enter after a formula. If you see #ERROR! or #VALUE!, click the cell and read the message—Sheets usually points at the problem range.

3. Decisions with IF

=IF(D2="Yes", "Here", "Not yet")

Drag the fill handle (small square at the cell’s corner) down the column to copy the formula. Relative references like D2 update per row; use $D$2 when you want a reference to stay fixed.

4. Share safely

  1. Click Share.
  2. Prefer “anyone with the link” only for practice sheets with fake data.
  3. Use Viewer for read-only, Commenter for feedback, Editor only for people who should change cells.

Advanced track

If the beginner steps already feel familiar, push further with lookups, charts, and sheet-to-sheet pulls.

1. Lookups

Keep a small reference table on a second tab (e.g. role → suggested table). Then:

=XLOOKUP(B2, Roles!A:A, Roles!B:B, "Unknown")

If XLOOKUP isn’t available in your account, VLOOKUP still works when the key is in the leftmost column of the lookup range.

2. QUERY for quick summaries

=QUERY(A1:D50, "select C, count(A) where C is not null group by C label count(A) 'Count'", 1)

QUERY uses a mini SQL-like language inside the sheet—great for pivot-style counts without a full pivot table UI.

3. Chart one question

  1. Select the summary range (categories + counts).
  2. Insert → Chart.
  3. Pick a bar or pie chart; edit the title so it states the question (“RSVPs by type”), not just “Chart 1.”

4. Pull from another workbook

=IMPORTRANGE("https://docs.google.com/spreadsheets/d/FILE_ID/edit", "Sheet1!A1:D50")

You must allow access the first time. Prefer IMPORTRANGE for living copies of a source of truth—not for one-off paste jobs.

Project ideas

  1. Meetup headcount — Name, RSVP, checked-in, count of “Yes.”
  2. Program supply list — Item, quantity needed, quantity on hand, IF to flag shortages.
  3. Simple budget — Date, category, amount, running SUM, category SUMIF.
  4. Volunteer shifts — Person, date, start/end, hours calculated from times.
  5. Reading challenge tracker — Title, pages, genre, progress chart.

Habits that save pain later

  • Headers in row 1; no blank rows inside the data block.
  • Raw data on one sheet; summaries and charts on another.
  • Never type a total you could formula.
  • Name ranges or use clear sheet tab names before formulas get long.
  • Fake data only on public share links.
